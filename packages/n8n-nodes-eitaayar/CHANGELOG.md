# Changelog

All notable changes to `n8n-nodes-eitaayar` are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## 0.1.0

First release.

- Eitaa (EitaaYar) node with Bot > Get Me and Message > Send Text / Send File.
- Scheduling, pinning, silent sending, replies and automatic deletion after a number of views.
- Token normalisation (the `bot` prefix is optional), token redaction in errors and multipart
  uploads without any runtime dependency.
