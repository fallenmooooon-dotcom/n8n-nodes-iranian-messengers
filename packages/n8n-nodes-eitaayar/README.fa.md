# n8n-nodes-eitaayar

نود انجمنی [n8n](https://n8n.io) برای **ایتایار** ([eitaayar.ir](https://eitaayar.ir)) که API ارسال پیام و فایل به
کانال‌ها و گروه‌های [ایتا](https://eitaa.com) است.

[English](README.md)

> این یک پروژه‌ی مستقل انجمنی است و ارتباط یا تأیید رسمی از طرف ایتا، ایتایار یا n8n ندارد.

## ایتایار همان پلتفرم برنامه‌های ایتا نیست

این بسته با API ایتایار (`https://eitaayar.ir/api/...`) کار می‌کند. برای پلتفرم برنامه‌های ایتا (mini-app) که در
`developer.eitaa.com` مستند شده **نیست**. ایتایار یک API فقط‌ارسال است و وب‌هوک یا پولینگ ندارد؛ پس این بسته
نود عملیاتی دارد و نود تریگر ندارد.

## امکانات

| منبع (Resource) | عملیات |
| --- | --- |
| Bot | Get Me |
| Message | Send Text، Send File |

## نصب

در n8n شخصی‌سازی‌شده (self-hosted) به **Settings → Community Nodes → Install** بروید و `n8n-nodes-eitaayar`
را وارد کنید. برای نصب با Docker یا نصب دستی به
[راهنمای n8n](https://docs.n8n.io/integrations/community-nodes/installation/) مراجعه کنید.

پیش‌نیازها: n8n نسخه‌ی 1.x و Node.js نسخه‌ی 20.19 یا بالاتر.

## اعتبارنامه (Credential)

1. در [eitaayar.ir](https://eitaayar.ir) حساب بسازید و کانال یا گروه خود را همان‌طور که ایتایار توضیح می‌دهد تنظیم کنید.
2. توکن API را از داشبورد ایتایار کپی کنید. داشبورد آن را با پیشوند `bot` نشان می‌دهد
   (`bot<digits>:<uuid>`). این پیشوند اختیاری است و خودکار حذف می‌شود؛ پس هر دو شکل کار می‌کند و چسباندن
   کل آدرس API هم مشکلی ندارد.
3. در n8n یک اعتبارنامه‌ی **EitaaYar API** بسازید و توکن را در **Access Token** وارد کنید.
4. مقدار پیش‌فرض **Base URL** برابر `https://eitaayar.ir/api` است. فقط در صورت استفاده از پروکسی آن را تغییر دهید.
5. روی **Save** بزنید. n8n با فراخوانی `getMe` اعتبارنامه را آزمایش می‌کند.

توکن بخشی از آدرس همه‌ی درخواست‌هاست. نود توکن را از پیام‌های خطا حذف می‌کند.

## نحوه‌ی استفاده

### ارسال پیام متنی

**Message → Send Text** را انتخاب کنید و **Chat ID** و **Text** را تنظیم کنید.

مقدار **Chat ID** شناسه‌ی کانال یا گروه در پنل ایتایار است، یا نام‌کاربری کانال با `@` یا بدون آن.

### ارسال فایل

**Message → Send File** را انتخاب کنید و **Chat ID** و **Input Binary Field** (ویژگی باینری حاوی فایل) را تنظیم
کنید؛ مثلاً خروجی نود **Read/Write Files from Disk** یا **HTTP Request**. فایل با multipart/form-data آپلود
می‌شود.

ایتایار نوع رسانه را از پسوند نام فایل تشخیص می‌دهد. با **File Name** می‌توانید نام آپلود را تغییر دهید:
برای GIF پسوند `.gif` و برای استیکر پسوند `.webp` لازم است.

### فیلدهای اضافی

| فیلد | اثر |
| --- | --- |
| Caption (فقط Send File) | متنی که همراه فایل فرستاده می‌شود |
| Delete After Views | پیام پس از این تعداد بازدید خودکار حذف می‌شود |
| Disable Notification | ارسال بی‌صدا |
| Pin | پین‌کردن پیام در کانال |
| Reply To Message ID | پاسخ به یک پیام |
| Schedule Date | ارسال پیام در زمانی بعدی. تاریخ بدون اختلاف منطقه‌ی زمانی بر اساس منطقه‌ی زمانی سرور n8n خوانده می‌شود |
| Title | عنوانی که فقط داخل پنل ایتایار نمایش داده می‌شود |

نود فیلدهای روشن/خاموش را همان‌طور که ایتایار انتظار دارد با مقدار `1` می‌فرستد و برای فیلدهایی که تنظیم
نکرده‌اید چیزی نمی‌فرستد.

### محدودیت نرخ و حجم

نود خودش محدودیتی برای نرخ ارسال یا حجم فایل اعمال نمی‌کند؛ ایتایار محدودیت‌های خودش را دارد. هنگام ارسال
پیام‌های پشت‌سرهم از **Options → Delay Between Items (Ms)** استفاده کنید و برای خطاهای موقت **Retry On Fail** را
فعال کنید.

## خروجی

| عملیات | آیتم خروجی |
| --- | --- |
| Get Me | شیء حساب برگشتی از ایتایار (`id`، `is_bot`، `first_name`، `last_name`، `username`) |
| Send Text، Send File | شیء `result` پاسخ، یا `{ "success": true }` اگر ایتایار چیزی برنگرداند |

ایتایار با فلگ `ok` پاسخ می‌دهد. وقتی مقدار آن `false` باشد، نود با پیام `EitaaYar API error: <description>`
(یا کد HTTP در صورت نبود توضیح) شکست می‌خورد. با **Continue On Fail**، آیتمی که خطا بدهد به
`{ "error": "..." }` تبدیل می‌شود و ارتباطش با آیتم ورودی حفظ می‌شود.

## توسعه

```bash
git clone https://github.com/mehran-asgharian/n8n-nodes-iranian-messengers.git
cd n8n-nodes-iranian-messengers
npm install
npm run build --workspace packages/n8n-nodes-eitaayar
npm run lint --workspace packages/n8n-nodes-eitaayar
npm test --workspace packages/n8n-nodes-eitaayar
```

تست‌های واحد از context ساختگی n8n و پاسخ‌های HTTP از پیش تعیین‌شده استفاده می‌کنند. برای آزمایش با API واقعی،
فایل `examples/smoke-test.workflow.json` را وارد کنید و اعتبارنامه‌ی ایتایار را انتخاب کنید. **Execute workflow**
نود **Get Me** را برای بررسی توکن اجرا می‌کند. نود آخر که پیام آزمایشی می‌فرستد غیرفعال است، چون به کانال
خود شما نیاز دارد: کانال را در **Chat ID** وارد کنید و برای آزمایش ارسال، نود را فعال کنید.

انتشار نسخه‌ها با GitHub Actions و همراه با provenance در npm انجام می‌شود؛ کافی است تگی مانند
`eitaayar-v0.1.0` را push کنید. توکن npm از secret مخزن با نام `NPM_TOKEN` خوانده می‌شود.

## منابع

متدها و پارامترها از راهنمای API ایتایار در [eitaayar.ir](https://eitaayar.ir) پیروی می‌کنند. قالب پاسخ (`ok` و `result`)
از یادداشت‌های نگه‌دارنده درباره‌ی همان راهنما گرفته شده است.
