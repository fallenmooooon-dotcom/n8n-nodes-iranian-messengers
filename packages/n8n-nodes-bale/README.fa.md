# n8n-nodes-bale-ir

نودهای انجمنی [n8n](https://n8n.io) برای API ربات‌های پیام‌رسان [بله](https://bale.ai).
با این نودها می‌توانید از داخل ورک‌فلوهای n8n پیام و فایل بفرستید، چت‌ها را مدیریت کنید و به
پیام‌های دریافتی و فشرده‌شدن دکمه‌ها واکنش نشان دهید.

[English](README.md)

> این یک پروژه‌ی مستقل انجمنی است و ارتباط یا تأیید رسمی از طرف بله یا n8n ندارد.

## امکانات

| نود | کاربرد |
| --- | --- |
| **Bale** | فراخوانی API ربات بله از داخل ورک‌فلو |
| **Bale Trigger** | شروع ورک‌فلو هنگام دریافت آپدیت از بله (وب‌هوک) |

### عملیات نود Bale

| منبع (Resource) | عملیات |
| --- | --- |
| Bot | Get Me |
| Callback Query | Answer |
| Chat | Get، Get Member Count، Leave، Pin Message، Unpin Message، Unpin All Messages |
| Chat Member | Ban، Unban |
| File | Get (اطلاعات فایل و در صورت نیاز دانلود به‌صورت داده‌ی باینری) |
| Message | Send Text، Send Media (عکس، صوت، سند، ویدیو، پیام صوتی، انیمیشن)، Send Location، Send Contact، Forward، Copy، Edit Text، Delete |

### نود Bale Trigger

آپدیت‌های **Message**، **Edited Message** و **Callback Query** را دریافت می‌کند. در صورت فعال
بودن گزینه‌ی دانلود، عکس، صوت، سند، ویدیو، پیام صوتی یا انیمیشن پیام را به‌صورت داده‌ی باینری
ذخیره می‌کند.

## نصب

در n8n شخصی‌سازی‌شده (self-hosted) به **Settings → Community Nodes → Install** بروید و
`n8n-nodes-bale-ir` را وارد کنید. برای نصب با Docker یا نصب دستی به
[راهنمای n8n](https://docs.n8n.io/integrations/community-nodes/installation/) مراجعه کنید.

پیش‌نیازها: n8n نسخه‌ی 1.x و Node.js نسخه‌ی 20.19 یا بالاتر.

## اعتبارنامه (Credential)

1. در بله با **@botfather** گفتگو کنید و یک ربات بسازید. توکن ربات را از BotFather دریافت می‌کنید.
2. در n8n یک اعتبارنامه‌ی **Bale API** بسازید و توکن را در **Access Token** وارد کنید.
   اگر توکن با پیشوند `bot` شروع شود، این پیشوند خودکار حذف می‌شود؛ پس هر دو شکل
   `123456:ABC...` و `bot123456:ABC...` کار می‌کنند.
3. مقدار پیش‌فرض **Base URL** برابر `https://tapi.bale.ai` است. فقط در صورت استفاده از پروکسی یا
   محیط آزمایشی آن را تغییر دهید. اسلش انتهایی نادیده گرفته می‌شود.
4. روی **Save** بزنید. n8n با فراخوانی `getMe` اعتبارنامه را آزمایش می‌کند.

توکن بخشی از آدرس همه‌ی درخواست‌های بله است. این نودها توکن را از پیام‌های خطا حذف می‌کنند و
آدرس دانلود فایل (که شامل توکن است) را هرگز در خروجی قرار نمی‌دهند.

## نحوه‌ی استفاده

### ارسال پیام متنی

1. یک نود **Bale** اضافه کنید و **Message → Send Text** را انتخاب کنید.
2. در **Chat ID** شناسه‌ی عددی چت یا نام‌کاربری کانال مانند `@my_channel` را بنویسید.
3. **Text** را وارد کنید (۱ تا ۴۰۹۶ نویسه).

فیلدهای اختیاری: **Reply To Message ID**، **Reply Markup (JSON)** و **Parse Mode**.
مقدار **Parse Mode** فقط وقتی ارسال می‌شود که آن را پر کنید، چون بله از همه‌ی قابلیت‌های
Markdown و HTML تلگرام پشتیبانی نمی‌کند.

### ارسال فایل

**Message → Send Media** را انتخاب کنید، **Media Type** را تعیین کنید و یکی از سه منبع را بردارید:

| منبع | محدودیت اعلام‌شده توسط بله |
| --- | --- |
| Binary Data (آپلود با multipart/form-data) | عکس تا ۱۰ مگابایت، سایر انواع تا ۵۰ مگابایت |
| URL (بله فایل را دانلود می‌کند) | عکس ۵ مگابایت، سایر انواع ۲۰ مگابایت |
| File ID (فایلی که قبلاً روی بله ذخیره شده) | محدودیتی ذکر نشده |

حجم آپلود پیش از ارسال درخواست با محدودیت‌ها مقایسه می‌شود. کپشن حداکثر ۱۰۲۴ نویسه دارد.
برای انیمیشن کپشن ارسال نمی‌شود، چون مستندات بله برای آن کپشنی تعریف نکرده است.

### دکمه‌ها

فیلد **Reply Markup (JSON)** یک شیء JSON می‌گیرد که از ساختار کیبوردهای مستندات API ربات بله
پیروی می‌کند. نمونه‌ی کیبورد درون‌خطی:

```json
{
  "inline_keyboard": [
    [
      { "text": "Open website", "url": "https://example.com" },
      { "text": "Confirm", "callback_data": "confirm" }
    ]
  ]
}
```

وقتی کاربر دکمه‌ای با `callback_data` را فشار می‌دهد، **Bale Trigger** (با انتخاب **Callback Query**)
آپدیت را می‌فرستد. برای تأیید دریافت از **Callback Query → Answer** با مقدار
`{{ $json.callback_query.id }}` استفاده کنید.

### دریافت پیام

1. یک **Bale Trigger** اضافه کنید و نوع آپدیت‌ها را انتخاب کنید.
2. ورک‌فلو را فعال کنید. n8n آدرس وب‌هوک خود را با `setWebhook` در بله ثبت می‌کند و هنگام
   غیرفعال‌کردن ورک‌فلو آن را حذف می‌کند.

بله وب‌هوک را فقط به آدرس‌های **HTTPS** روی پورت **۴۴۳ یا ۸۸** ارسال می‌کند. تریگر پیش از ثبت،
آدرس را بررسی می‌کند و در صورت مشکل توضیح می‌دهد چه چیزی را باید تغییر دهید. n8n را روی یک
آدرس عمومی HTTPS در دسترس قرار دهید و متغیر محیطی `WEBHOOK_URL` را روی همان آدرس تنظیم کنید.
آدرس وب‌هوک را محرمانه نگه دارید، چون شامل یک شناسه‌ی تصادفی است.

گزینه‌ی **Download Media** رسانه‌ی پیام را در ویژگی باینری انتخابی (پیش‌فرض `data`) ذخیره
می‌کند. اگر دانلود شکست بخورد، پیام همچنان با فیلد `mediaDownloadError` ارسال می‌شود.

### محدودیت نرخ ارسال

بله تقریباً یک پیام در ثانیه به یک چت و حدود ۲۰ تا ۳۰ پیام در ثانیه در مجموع چت‌ها مجاز
می‌داند. هنگام ارسال پیام‌های زیاد به یک چت از **Options → Delay Between Items (Ms)** (مثلاً
`1000`) استفاده کنید و برای خطاهای موقت **Retry On Fail** را فعال کنید. خطاهای ۴۰۰، ۴۰۱، ۴۰۳،
۴۰۴ و ۴۲۹ همراه با راهنمای علت رایج نمایش داده می‌شوند.

## خروجی

| عملیات | آیتم خروجی |
| --- | --- |
| عملیاتی که شیء برمی‌گردانند (ارسال، فوروارد، کپی، ویرایش، دریافت) | همان شیء بازگشتی از بله |
| عملیاتی که `true` برمی‌گردانند (حذف، پین، مسدودسازی، پاسخ، ...) | `{ "success": true }` |
| Chat → Get Member Count | `{ "count": 42 }` |
| File → Get همراه با **Download** | اطلاعات فایل به‌همراه فایل به‌صورت باینری |
| Bale Trigger | شیء `Update` بله |

با فعال‌بودن **Continue On Fail**، آیتمی که خطا بدهد به `{ "error": "..." }` تبدیل می‌شود و
ارتباطش با آیتم ورودی حفظ می‌شود.

## توسعه

```bash
git clone https://github.com/mehran-asgharian/n8n-nodes-iranian-messengers.git
cd n8n-nodes-iranian-messengers
npm install
npm run build     # ساخت همه‌ی بسته‌ها
npm run lint      # بررسی با linter نودهای انجمنی n8n
npm test          # تست‌های واحد (بدون شبکه و بدون توکن واقعی)
```

برای اجرای یک بسته از `npm run <script> --workspace packages/n8n-nodes-bale` استفاده کنید.
اجرای n8n همراه با نود در حال توسعه با `npm run dev --workspace packages/n8n-nodes-bale` انجام می‌شود.

تست‌های واحد از contextهای ساختگی n8n و پاسخ‌های HTTP از پیش تعیین‌شده استفاده می‌کنند. برای
آزمایش با API واقعی، فایل `examples/smoke-test.workflow.json` را در n8n وارد کنید، اعتبارنامه‌ی بله
را روی نودها انتخاب کنید، برای بررسی توکن روی **Execute workflow** بزنید و برای دیدن پاسخ
echo به ربات خود پیام بفرستید.

انتشار نسخه‌ها با GitHub Actions و همراه با provenance در npm انجام می‌شود؛ کافی است تگی مانند
`bale-v0.1.0` را push کنید. توکن npm از secret مخزن با نام `NPM_TOKEN` خوانده می‌شود.

## منابع

قالب درخواست‌ها و پاسخ‌ها از مستندات API ربات بله در [docs.bale.ai](https://docs.bale.ai/)
پیروی می‌کند. متد `answerCallbackQuery`، کدهای خطا و محدودیت‌های نرخ ارسال از یادداشت‌های
نگه‌دارنده‌ی پروژه درباره‌ی همان مستندات گرفته شده‌اند.
